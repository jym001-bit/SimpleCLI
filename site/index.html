01 Execution
modes

任务有多复杂，
就用多重的思考方式。

三条路径，一套底座。切换的是策略，共享的是工具、记忆和快照。 普通输入走 ReAct，/plan 进入计划执行，/team 拉起多角色协作。

ReAct边想边干 / 默认入口

单代理循环：Thought → Action → Observation。定位一个报错、改一个文件、查一段资料，直接说就行。只读工具会并行执行，写操作按顺序串行。

默认入口并行只读工具流式输出
terminal>把这个 NPE 修掉，并补一个测试
Plan-and-Execute先画图，再施工

把任务拆成带依赖的 DAG，动手前先给你过目。跨模块改造、批量重构，每一步都看得见、拦得住；独立任务按依赖批次并行推进。

/planDAG 依赖执行前确认
terminal/plan给订单模块加限流和降级
Multi-Agent组队干活 / 质量门槛

Planner 拆解，Worker 执行，Reviewer 审查。审查不通过就带反馈重试，最多两次；计划和审查结论都按 JSON 严格解析，解析失败按未通过处理。

/team角色分工自动返工
terminal/team重构遗留模块，保持行为不变

三条路径共享 ToolRegistry / MemoryManager / SnapshotService，不为某个模式制造孤立的能力孤岛。

02 The
workbench

工具不是摆设，
是一套能收尾的工作台。

从定位代码到验证结果，每一环都有对应的工具；需要更多能力时，接 MCP，或者写一个 Skill。 工具默认开放给模型，但能不能动手，还要过策略层。

代码理解

glob / grep / read 先找真实代码；RAG 语义检索和代码关系图谱只做模糊补充，不拿相似度冒充事实。

JavaParser · SQLite · Ollama

文件与命令

读写、编辑、建项目、跑 Shell。写入单文件 5MB 上限，命令 60 秒超时，输出超长会被截断。

PathGuard · 60s timeout

联网与浏览器

web_search 支持多条搜索路径，web_fetch 提取正文；SPA、防爬墙和登录态页面交给 Chrome DevTools MCP。

Search · Fetch · Chrome

MCP

stdio 子进程与 Streamable HTTP 都能接，工具自动注册为 mcp__server__tool，支持 resources 与 prompts。

stdio + HTTP · 60s init

Skill

把专家手册打包成目录，模型按需 load_skill。不往 system prompt 里硬塞，也不怕越写越长。

SKILL.md · references

记忆

PAI.md 存团队规则，长期记忆存稳定事实；自动提取的条目标为待核实，冲突时先问你。

PAI.md · 待核实 · 项目级

上下文

按模型窗口动态算预算；先清理旧工具结果，再摘要压缩。大窗口模型可到 1M，prompt cache 模式可见。

1M window · auto compact

快照回滚

每个 turn 前后用 side-git 留快照，不碰项目 .git。/restore N 回到任意 pre-turn，恢复前再留一份。

JGit · pre/post-turn

多端入口

inline TUI、全屏 TUI、plain 三种形态；Runtime API 跑后台任务，微信 iLink 通道收发消息，图片用 @image: 贴进来。

TUI · HTTP API · WeChat
03 One
turn

从一句话，
到一次可回滚的改动。

一次任务的完整闭环。不是“模型说了什么”，而是“它做了什么、你怎么拦、事后怎么退”。

01 / INPUT

接收

解析 @path 和 @image:，判断要不要联网；标题式输入先问清楚目标。

02 / LOCATE

定位

glob / grep / read 先找真实代码，RAG 只在关键词模糊时补位。

03 / PLAN

计划

简单任务直接做；复杂任务拆成 DAG，执行前给你过目。

04 / ACT

执行

只读工具并行，写操作串行；危险动作走 HITL 审批。

05 / VERIFY

验证

跑测试、读诊断；LSP 错误在下一轮请求前注入。

06 / KEEP

留痕

审计日志、完整会话、pre/post-turn 快照，都能回看。

04 Guard
rails

放手让它干，
不等于把门打开。

PaiCLI 把“能做什么”和“允许做什么”分开：工具负责能力，策略层负责边界，你负责最后那一下确认。

路径围栏

文件类工具只能在项目根内活动，绝对路径外逃、.. 穿越、符号链接逃逸都会被拦下。

命令快拒

sudo、rm -rf 全盘、mkfs、curl | sh 等黑名单在 HITL 之前直接拒绝，减少弹窗骚扰。

分级审批

auto 默认不打断，Shell 命令先由轻量分类器审查；/hitl on 切到逐项确认。连续被拦 3 次才弹审批。

结构化审计

危险调用按天写 JSONL 到 ~/.paicli/audit，记录 allow / deny / error 和审批来源。

可选沙箱

PAICLI_COMMAND_SANDBOX=auto 时走 Seatbelt 或 bubblewrap；默认 off，因为 mvn、npm install 需要网络和用户目录。

HITL / 审批 需要确认
execute_command
mvn clean package
风险 高危 · 工作区 D:\work\order-service
命令将在项目根目录执行
[y] 批准 [n] 拒绝 [a] 全部放行 [s] 跳过 [m] 修改参数
auto 模式下低风险命令直接执行；这里的弹窗只用于有风险或需要你决定的动作。

策略层不是沙箱，不提供进程隔离。进程隔离由可选的命令沙箱负责，默认关闭。

05 Quick
start

三步，
进你的终端。

需要 Java 17 和 Maven。默认接入 DeepSeek V4.1 Flash，也可以在会话里随时 /model 切换。

01

配置 API Key

复制模板，填入 DEEPSEEK_API_KEY。也支持 GLM、混元、StepFun、Kimi、FreeLLMAPI、讯飞星辰和 Agnes。

# 项目根目录
$ cp .env.example .env
02

构建

默认跳过测试，先产出一个能手工试用的 jar；需要回归时再按范围跑测试。

$ mvn clean package
03

运行

进入 inline TUI。首次启动会自动创建 ~/.paicli/mcp.json，默认接入 chrome-devtools。

$ java -jar target/paicli-1.0-SNAPSHOT.jar
# Windows 也可以直接
$ start-paicli.bat

完整配置、MCP 与命令说明见 README Runtime API：serve --http --port 8080
