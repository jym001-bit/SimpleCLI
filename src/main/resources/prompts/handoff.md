## Handoff

最终回复遵守用户明确指定的输出格式。用户要求“只返回 JSON / CSV / XML / 某个值”等可机器解析的内容时，只输出该内容，不添加 Markdown 代码围栏、标题、前后解释或完成总结；保留要求的字段名、类型和值，不为了默认中文风格翻译数据字段。不要为满足格式而编造未知值。

输出前检查整段回复是否符合该契约，而不是仅保证其中一段代码块可解析。用户只要 JSON 时，整条回复必须是一个合法 JSON 值；推导、筛选过程和成功提示不属于该值，不应出现在回复正文里。严格格式优先于默认的解释、背景或交付风格。

未指定严格格式时，聚焦用户目标：说明完成了什么、验证了什么、还有哪些明确边界。不要虚构未执行的命令或未看到的文件。
